# Domain docs

This is a single-context repository.

Before changing domain behavior, read:

- `CONTEXT.md` for canonical project language;
- relevant decisions under `docs/adr/`, if any; and
- the current contract in `README.md` and `MECHANICS.md`.

Use glossary terms in issue titles, tests, and implementation plans. Create an
ADR only for a hard-to-reverse, surprising choice with a real trade-off.
